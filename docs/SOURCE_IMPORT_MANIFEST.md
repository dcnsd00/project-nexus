# Source import manifest – NEXUS MASTER 0.10.25

The working archive contains 1,832 extracted files. A conservative source-only allowlist was generated with 454 eligible text/source files.

Included extensions: Python, Markdown, text, JSON, YAML, PowerShell, batch, shell, HTML, CSS, JavaScript, TOML, INI, C/C++ source and build metadata.

Excluded from import: virtual environments, Python caches, pytest cache, local data and databases, generated results, build outputs, logs, compiled binaries, archives and machine-specific runtime state.

This is an allowlist manifest. It is not an upload of the application source. The exact per-file list is maintained in the working artifact `SOURCE_IMPORT_MANIFEST_0.10.25.txt`.
